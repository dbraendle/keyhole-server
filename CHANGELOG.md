# Changelog

## 0.7.0

- The server lives in its own repository now (it was the `server/` folder of dbraendle/obsidian-keyhole). The image name `ghcr.io/dbraendle/keyhole-server` and the HTTP interface are unchanged.
- The image carries a build provenance attestation; the base image is pinned by digest.

Earlier versions were released together with the plugin and carry its version numbers (0.1.0 – 0.6.0). The server code itself is unchanged since 0.4.0.
